# 🧠 Sistema de Gestão de Inventário
O Sistema de Gestão de Inventário é um aplicativo completo projetado para gerenciar categorias, produtos e produtos perecíveis. Ele oferece uma interface amigável para interação com o inventário, permitindo que os usuários adicionem, listem e removam categorias, produtos e produtos perecíveis. O sistema também inclui recursos para listar produtos vencidos e gerenciar quantidades de produtos.

## 🚀 Funcionalidades
- **Gestão de Categorias**: Adicione, liste e remova categorias
- **Gestão de Produtos**: Adicione, liste e remova produtos
- **Gestão de Produtos Perecíveis**: Adicione, liste e remova produtos perecíveis
- **Listagem de Produtos Vencidos**: Liste os produtos que expiraram
- **Gestão de Quantidades**: Gerencie as quantidades de produtos

## 🛠️ Tecnologias
- **Backend**: C#, .NET Framework 4.7.2
- **Banco de Dados**: Não especificado (potencial para integração com banco de dados)
- **Interface do Usuário**: Interface de usuário baseada em console
- **Dependências**: System, System.Collections.Generic, System.IO, System.Text.Json
- **Configuração**: Arquivo App.config para configuração do ambiente de execução

## 📦 Instalação
Para instalar o Sistema de Gestão de Estoque, siga estes passos:
1. **Pré-requisitos**: Certifique-se de ter o .NET Framework 4.7.2 instalado. seu sistema.
2. **Clone o Repositório**: Clone o repositório para sua máquina local.
3. **Compile o Projeto**: Compile o projeto usando o Visual Studio ou a CLI do .NET.
4. **Execute o Aplicativo**: Execute o aplicativo usando o arquivo executável ou a CLI do .NET.

## 💻 Uso
Para usar o Sistema de Gerenciamento de Estoque, siga estas etapas:
1. **Execute o Aplicativo**: Execute o aplicativo usando o arquivo executável ou a CLI do .NET.

2. **Interaja com a Interface do Usuário**: Interaja com a interface do usuário baseada em console para gerenciar categorias, produtos e produtos perecíveis.
